# 🦉 Good Diagon Alley — Интерактивная Лавка Артефактов Гарри Поттера

Полноценное full-stack веб-приложение волшебного магазина Косого Переулка, созданное на **Next.js 15**, **Neon (Lakebase Postgres, Object Storage, Realtime)** и винтажной дизайн-системе **Oldbook.css**.

## ✨ Основные возможности

1. **Дизайн-система Oldbook.css**:
   - Эстетика древнего пергамента (`#fff3c9`), чернильных заголовков (`#8b0000`), буквиц (`.has-dropcap`), анимаций переворота страниц и звуковых эффектов Web Audio API.
   - SPA-переключение вкладок без перезагрузки страницы, переключатель валют (**USD $ / UZS сум**) и промокоды (`LUMOS10` — 10%, `ALOHOMORA` — 20%, `FELIX25` — 25%).
2. **Инфраструктура Neon**:
   - **Neon Postgres (`pg` + `@vercel/functions`)**: пользователи, 6 категорий, 37 товаров, избранное, предзаказы (`pending_checkouts`), оплаченные заказы (`orders`), 355 вопросов викторины на русском языке (`quiz_questions`) и таблица рекордов.
   - **Neon Object Storage (`files-sdk` + `@aws-sdk/client-s3`)**: загрузка и раздача изображений товаров из Админ-панели.
   - **Neon Realtime (`@neon/realtime` + `@neon/realtime-react`)**: live-обновления таблицы рекордов и статусов заказов.
3. **Каталог из 6 категорий**:
   - `Форма` (Гриффиндор, Слизерин, Когтевран, Пуффендуй, Дурмстранг, Шармбатон)
   - `Палочки` (Бузинная палочка, палочки Гарри, Волан-де-Морта, Рона, Гермионы, Снейпа)
   - `Сладости` (Берти Боттс, Шоколадные лягушки с карточками, Сливочное пиво, Взрывающиеся леденцы, Забастовочные завтраки)
   - `Спорт инвентарь` (Нимбус-2000, Молния, Золотой снитч, Квоффл, Бладжеры, Перчатки вратаря)
   - `Артефакты` (Письмо из Хогвартса, Карта Мародёров, Мантия-невидимка, Философский камень, Воскрешающий камень, Корона Кандиды, Маховик времени)
   - `Фигурки` (Добби, Букля, Клювокрыл, Василиск, Дамблдор, Снейп)
4. **Двойная платёжная система (Только оплаченные заказы попадают в `orders`!)**:
   - **Stripe (Test Mode)**: тестовая карта `4242 4242 4242 4242` -> вебхук `/api/webhooks/stripe`.
   - **Payme / Click Sandbox**: тестовая карта `8600 0000 0000 0000` + SMS-код `666666` -> вебхуки `/api/webhooks/payme` (JSON-RPC) и `/api/webhooks/click` (Prepare/Complete).
5. **Интеграция с Telegram-ботом (`@wizard_HP_store_bot`)**:
   - Глубокая ссылка после оплаты: `https://t.me/wizard_HP_store_bot?start=order_<ORDER_ID>`.
   - Приём адреса или геолокации от покупателя -> смена статуса на `"Готовится к отправке"` и уведомление Админа (`3540653`).
   - Кнопка **«Отправить заказ»** в `/admin` (и в чате Админа) -> уведомление покупателя: *"Ваш заказ отправлен совиной почтой! 🦉"*.
6. **Мини-игры и Энциклопедия**:
   - **История Хогвартса (FAQ)** в формате иллюстрированной книги.
   - **Распределяющая Шляпа (10 вопросов)**: вопрос №1 — выбор пола; Дурмстранг доступен только для мужского пола, Шармбатон — только для женского.
   - **Викторина по миру Гарри Поттера**: 10 случайных вопросов из пула 250+ (355 уникальных вопросов на русском языке), расчёт Магического Ранга и Глобальная Таблица Рекордов.
